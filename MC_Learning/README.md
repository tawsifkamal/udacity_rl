# Blackjack Using Every-Visit Monte Carlo Epsilon Greedy Strategy

This project solves the OpenAI Blackjack Gym environment using the Every-visit Monte Carlo learning method with a constant alpha and epsilon greedy strategy.

The implementation details are in the `mc_blackjack.ipynb` Jupyter notebook.

## How to Run
1. Make sure you have Jupyter Notebook installed. You can install it with pip:
   ```bash
   pip install notebook
   ```
2. Navigate to the `MC_Learning` directory in your terminal.
3. Launch the Jupyter Notebook server:
   ```bash
   jupyter notebook
   ```
4. This will open a new tab in your browser. From the file list, click on `mc_blackjack.ipynb`.
5. Once the notebook is open, you can run all the cells to train the agent and visualize the results.
