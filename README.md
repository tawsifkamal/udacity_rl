# Projects For Udacity Nanodegree RL Program
This repository contains all of my projects for the udacity Reinforcement Learning nanodegree program.

## Projects
1. **Playing Blackjack using Monte Carlo learning with the epsilon greedy strategy**
   - This project is located in the `MC_Learning` directory and is implemented in a Jupyter notebook (`mc_blackjack.ipynb`).
   - It uses the Every-visit Monte Carlo learning method with a constant alpha and epsilon greedy strategy to solve the open AI Blackjack Gym environment.
2. **Solving the Taxi-v0 environment using Temporal Difference Control Methods of SARSA(0) and Q-learning**
   - This project is located in the `taxi_rl/lab-taxi` directory.
   - The goal is to develop a reinforcement learning agent to solve the Taxi-v0 environment from OpenAI Gym.

## Getting Started
To get started with these projects, you'll need to have Python 3 and the following libraries installed:
- numpy
- gym
- matplotlib

You can install these libraries using pip:
```bash
pip install numpy gym matplotlib
```
